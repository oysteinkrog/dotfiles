# Property Tests — Explicit Hypothesis / proptest / fast-check Specifications

The five baseline Phase-5 verifiers test specific failure modes via fixtures. Property tests, generated by `/testing-metamorphic`, generalize to any state the doctor might encounter. This file pins which properties to assert per dimension and shows them in three languages.

A property test runs a fixed predicate against many randomly-generated inputs (typically 1000+). When it fails, the test framework minimizes the input to a smallest-failing-case. This catches whole classes of bugs the per-FM fixtures miss.

---

## Property catalog

### P1 — Reversibility under arbitrary mutation

**Property.** For any sequence of fixers F₁, F₂, ..., Fₙ applied via `<tool> doctor --fix --only Fᵢ`, the inverse sequence `<tool> doctor undo runᵢ` for i in n..1 restores byte-for-byte to the pre-F₁ state.

**Why:** generalizes Axiom 3 (reversible) to arbitrary fixer sequences. The per-FM `verify-undo.sh` only tests one FM at a time; this catches inter-fixer interference.

**Hypothesis (Python):**

```python
from hypothesis import given, strategies as st
from hypothesis.stateful import RuleBasedStateMachine, rule, invariant

class DoctorReversibility(RuleBasedStateMachine):
    def __init__(self):
        super().__init__()
        self.sandbox = mktemp_dir()
        self.run_ids: list[str] = []
        self.initial_state_hash = sha256_dir(self.sandbox)

    @rule(fm_id=st.sampled_from(KNOWN_FMS))
    def apply_fixer(self, fm_id):
        # Corrupt + fix.
        run_corrupt_for_fm(fm_id, self.sandbox)
        result = run_doctor_fix(self.sandbox, only=fm_id)
        if result.run_id:
            self.run_ids.append(result.run_id)

    @invariant()
    def undo_restores_byte_identical(self):
        # For each run in reverse, undo. Final state should match initial.
        for run_id in reversed(self.run_ids):
            run_doctor_undo(self.sandbox, run_id)
        final_hash = sha256_dir(self.sandbox)
        assert final_hash == self.initial_state_hash, \
            f"undo did not restore to initial state"
```

**proptest (Rust):**

```rust
use proptest::prelude::*;

proptest! {
    #[test]
    fn reversibility_under_arbitrary_fix_sequence(
        fm_sequence in proptest::collection::vec(any::<KnownFm>(), 1..=5)
    ) {
        let sandbox = setup_clean_sandbox();
        let initial_hash = sha256_dir(&sandbox);
        let mut run_ids = vec![];
        for fm in &fm_sequence {
            corrupt_for_fm(fm, &sandbox);
            let result = run_doctor_fix(&sandbox, &[fm]);
            if let Some(rid) = result.run_id {
                run_ids.push(rid);
            }
        }
        for rid in run_ids.iter().rev() {
            run_doctor_undo(&sandbox, rid);
        }
        let final_hash = sha256_dir(&sandbox);
        prop_assert_eq!(initial_hash, final_hash);
    }
}
```

**fast-check (TypeScript):**

```typescript
import * as fc from "fast-check";

fc.assert(
    fc.property(
        fc.array(fc.constantFrom(...KNOWN_FMS), { minLength: 1, maxLength: 5 }),
        async (fmSequence) => {
            const sandbox = await mkTempDir();
            const initialHash = await sha256Dir(sandbox);
            const runIds: string[] = [];
            for (const fm of fmSequence) {
                await corruptForFm(fm, sandbox);
                const result = await runDoctorFix(sandbox, [fm]);
                if (result.runId) runIds.push(result.runId);
            }
            for (const rid of runIds.reverse()) {
                await runDoctorUndo(sandbox, rid);
            }
            const finalHash = await sha256Dir(sandbox);
            return finalHash === initialHash;
        }
    ),
    { numRuns: 100 }
);
```

### P2 — Idempotence under repeated fix

**Property.** For any FM, applying `--fix` once then applying `--fix --only same-fm` again reports `actions_taken: 0`.

**Why:** generalizes Axiom 4 (idempotent) to all FMs.

**Implementation sketch:**
```python
@given(fm=st.sampled_from(KNOWN_FMS))
def test_idempotent(fm):
    sandbox = mktemp_dir()
    corrupt_for_fm(fm, sandbox)
    run_doctor_fix(sandbox, only=fm)
    second = run_doctor_fix(sandbox, only=fm)
    assert second.actions_taken == 0
```

### P3 — Detector purity (no observable mutation)

**Property.** For any sequence of detector calls (no `--fix`), the workspace is unchanged.

**Why:** generalizes Axiom 7 (read-only by default).

```python
@given(seq=st.lists(st.sampled_from(KNOWN_FMS), min_size=1, max_size=10))
def test_detector_purity(seq):
    sandbox = mktemp_dir()
    initial_hash = sha256_dir(sandbox, exclude=[".doctor"])
    for fm in seq:
        run_doctor_diagnose(sandbox, only=fm)  # no --fix
    final_hash = sha256_dir(sandbox, exclude=[".doctor"])
    assert initial_hash == final_hash
```

(Excludes `.doctor/` because diagnose creates run artifacts there; that's expected.)

### P4 — Concurrency safety (no double-fix)

**Property.** For any FM, two simultaneous `--fix` invocations result in EXACTLY one terminal state with `actions_taken > 0` and one with `exit_code == 5`.

**Why:** generalizes Axiom 6 (concurrency-safe).

```python
@given(fm=st.sampled_from(KNOWN_FMS))
def test_concurrency_safety(fm):
    sandbox = mktemp_dir()
    corrupt_for_fm(fm, sandbox)
    results = await asyncio.gather(
        run_doctor_fix_async(sandbox, only=fm),
        run_doctor_fix_async(sandbox, only=fm),
    )
    success_count = sum(1 for r in results if r.exit_code in (0, 2))
    locked_count = sum(1 for r in results if r.exit_code == 5)
    assert success_count == 1
    assert locked_count == 1
```

### P5 — Crash-safety (no torn writes)

**Property.** For any FM, killing the doctor mid-`--fix` at any nanosecond results in: (a) no orphaned `.doctor.tmp.<pid>` files; (b) the next `<tool> doctor` run either completes the partial fix or exits 4 cleanly.

**Why:** generalizes Axiom 5 (crash-recoverable).

This is harder to property-test deterministically. Use Hypothesis stateful + fault-injection points:

```python
class CrashRecovery(RuleBasedStateMachine):
    @rule(kill_after_ns=st.integers(min_value=1_000_000, max_value=100_000_000))
    def fix_with_kill(self, kill_after_ns):
        proc = run_doctor_fix_subprocess(self.sandbox)
        await asyncio.sleep(kill_after_ns / 1e9)
        proc.kill()
        proc.wait()

    @invariant()
    def no_orphan_tempfiles(self):
        orphans = find_files(self.sandbox, pattern=".doctor.tmp.*")
        assert len(orphans) == 0

    @invariant()
    def next_run_recovers(self):
        result = run_doctor(self.sandbox)
        assert result.exit_code in (0, 1, 4)  # no panic
```

### P6 — Capabilities reflective consistency

**Property.** For every detector ID in `<tool> doctor capabilities --json::detectors[].id`, invoking `<tool> doctor --only <id>` succeeds (exit 0 or 1).

**Why:** generalizes Axiom 11 (self-describing).

```python
@given(detector_id=st.sampled_from(get_capabilities()["detectors"]))
def test_declared_detectors_invocable(detector_id):
    sandbox = mktemp_clean_sandbox()
    result = run_doctor_diagnose(sandbox, only=[detector_id["id"]])
    assert result.exit_code in (0, 1)
```

(Already implemented in `scripts/verify-capabilities.sh` for one-shot; the property test extends to randomly-sampled subsets.)

### P7 — Schema stability across compatible versions

**Property.** A `report.json` produced by `<tool> doctor` v1.X is parseable by v1.Y for any X, Y in the same major version.

**Why:** generalizes [VERSIONING.md](VERSIONING.md) backward-compatibility within a major.

```python
@given(version_a=st.sampled_from(KNOWN_MINOR_VERSIONS),
       version_b=st.sampled_from(KNOWN_MINOR_VERSIONS))
def test_minor_version_schema_stability(version_a, version_b):
    if extract_major(version_a) != extract_major(version_b):
        return  # cross-major; out of scope
    report = run_doctor_with_version(version_a)
    parsed = parse_report_with_version_b_parser(report, version_b)
    assert parsed["schema_version"]
    assert parsed["run_id"]
```

### P8 — Bounded blast radius (writes within scope)

**Property.** For any `--fix` invocation, every path mutated is in `capabilities --json::write_scopes`.

**Why:** generalizes Axiom 14 (bounded blast radius).

```python
@given(fm_set=st.sets(st.sampled_from(KNOWN_FMS), min_size=1, max_size=5))
def test_writes_in_scope(fm_set):
    sandbox = mktemp_dir()
    for fm in fm_set:
        corrupt_for_fm(fm, sandbox)
    run_doctor_fix(sandbox, only=list(fm_set))
    actions = read_actions_jsonl(sandbox)
    write_scopes = get_capabilities()["write_scopes"]
    for action in actions:
        assert any(action["path"].startswith(s.lstrip("/")) for s in write_scopes), \
            f"action mutated path {action['path']} outside write_scopes"
```

### P9 — Deterministic run-id

**Property.** `run_id` is `sha256(target_sha + iso8601_utc_seconds)[:6]`. Same inputs always produce the same run-id; different inputs produce different ones.

**Why:** generalizes Axiom 13 (content-addressable).

```python
@given(target_sha=st.text(alphabet="0123456789abcdef", min_size=40, max_size=40),
       iso=st.datetimes(min_value=datetime(2026, 1, 1), max_value=datetime(2027, 1, 1)))
def test_run_id_determinism(target_sha, iso):
    iso_str = iso.strftime("%Y-%m-%dT%H:%M:%SZ")
    a = derive_run_id(target_sha, iso_str)
    b = derive_run_id(target_sha, iso_str)
    assert a == b
    assert len(a) == 6
```

### P10 — Backups byte-identical

**Property.** For any `--fix` that mutates path P from before-bytes B₀ to after-bytes B₁, the backup at `<run-dir>/backups/<P>` equals B₀ byte-for-byte.

**Why:** generalizes Axiom 2 (verbatim backup).

```python
@given(fm=st.sampled_from(KNOWN_MUTATING_FMS))
def test_backup_byte_identical(fm):
    sandbox = mktemp_dir()
    corrupt_for_fm(fm, sandbox)
    pre_state = snapshot_files(sandbox)
    result = run_doctor_fix(sandbox, only=fm)
    backups = read_backups_dir(sandbox, result.run_id)
    for path, backup_bytes in backups.items():
        original_bytes = pre_state[path]
        assert backup_bytes == original_bytes, \
            f"backup of {path} not byte-identical"
```

## How to add a property test

When a new axiom is added (or a new failure mode class emerges), think:

1. What's the universal predicate?
2. What's the input domain (what to randomly generate)?
3. What's the expected post-condition?

Then write a Hypothesis / proptest / fast-check test asserting the predicate holds for any input in the domain.

Add the new property to this catalog with a P-NN ID. Cite the axiom it generalizes.

## Performance budget

Each property test runs 100–1000 random inputs. Per-property budget: 10 minutes wall time. If a property exceeds, sample fewer inputs OR profile the per-iteration cost.

For CI, a "smoke" run does 50 inputs/property; nightly does 1000.
