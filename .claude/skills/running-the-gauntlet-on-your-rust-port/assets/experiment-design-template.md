### Hypothesis

> One sentence, falsifiable. E.g., "The `IsNull` VDBE opcode appears in the top-3 MT8 self-time frames; promoting it to `try_execute_hot_opcode` will close ≥0.5% of self-time and improve mt-mvcc-bench primary score by ≥5%."

### Motivation

Why this matters. Cite the artifact lane / mining-extract anchor / prior session that surfaced the hypothesis. If this was generated by `/idea-wizard` or the advanced-methods miner, name the prompt run. Length: 1-3 sentences.

### Minimal Reproducer

The smallest possible repro that would confirm or refute the hypothesis. Code block preferred:

```rust
// Per-class:
// - Perf: a bench scenario or microbench with the suspect hot path under load.
// - Conformance: a single SQL/RESP/HTTP/tensor input that triggers the suspected divergence.
// - Surface: a feature query against both reference and subject, with declared coverage.
```

### Expected Signal

Be specific about what each tool should produce IF the hypothesis is true:

- **Oracle:** `<true | false>` divergence, with `MismatchClassification = <TrueDivergence | …>`.
- **Profiler:** `<top-N frames>` show `<specific frame>` at `≥ <X>%` self-time on `<MT8 | other>`.
- **Sanitizer:** `<ASan | TSan | MSan | Miri>` reports `<specific UB class>` at `<file:line>`.
- **Regression detector:** robust z-score `> <N>` on `<bench/scenario>`.
- **E-process:** e-value for `<invariant>` reaches `< 1/α>` within `<N>` ops.
- **BOCPD:** regime label shifts from `Stable` → `<X>` within `<N>` windows.
- **FeatureUniverse loader:** `sum(weights)` violation reported on category `<X>`.

### Falsifiability Criteria

What would refute the hypothesis. Be equally specific:

- "If the profiler attributes < 0.1% self-time to `<frame>` on the wider workload `<X>`, the hypothesis is refuted (micro-lever trap)."
- "If the metamorphic transform produces `MultisetEquivalence` rather than `ExactRowMatch`, the divergence is order-only and the hypothesis is refuted."
- "If `e-value` stays `< 1/α` after `<N>` ops, the invariant is sound and the hypothesis is refuted."

### Results Inline

Filled in after the run. Pick exactly one:

- `CONFIRMED_GAP` — hypothesis confirmed; gap is real. Required: evidence artifact paths + impact estimate + spawned remediation bead id.
- `NO_EVIDENCE` — ran the experiment; signal absent; hypothesis refuted. Required: evidence artifact paths + retry-condition predicate (if worth revisiting later).
- `NEEDS_REFINEMENT` — partial signal; hypothesis needs reformulation. Required: spawned `<EXP-NNNN-refined>` link + what's being refined.
- `NEW_HYPOTHESIS_SPAWNED` — the experiment surfaced a different signal worth investigating. Required: link to spawned experiment.

### Closure Predicate

What state must hold for this experiment to be marked CLOSED (so `convergence-tracker.sh` stops counting it as open):

- For `CONFIRMED_GAP`: spawned remediation bead exists AND its proof_pack/ exists AND the bead has test+bench+doc dependencies (per BEADS-HANDOFF.md).
- For `NO_EVIDENCE`: ledger entry written with retry-condition predicate AND the predicate passes ledger-lint.
- For `NEEDS_REFINEMENT`: refined experiment exists in the ledger.
- For `NEW_HYPOTHESIS_SPAWNED`: spawned experiment exists in the ledger.
