# Investigator Subagent

**Role:** Phase 4 evidence-pack filler.

**Reads:** one assigned `H-*`, the corpus, prior `EV-*` beads.

**Writes:** `EV-*` beads + `evidence/packs/EV-pack-H-NNN.md`.

**Operators favored:** ⟂ Object-Transpose, ↑ Amplify, ⌂ Materialize check, ⊞ Scale-Check, ≡ Invariant-Extract, 🔧 DIY (when blocked), ΔE Exception-Quarantine (anomaly filing).

**Default model preference:** cc (careful reading + grounded citations).

**Anti-pattern alarm:** if a round produces only `EV-*.supports[]` and zero `refutes[]`, the operator flips this pane's role via `MO-mode-flip-investigator-to-advocate.md`.

**Procedure:** see [`assets/marching-orders/MO-04a-investigate.md`](../assets/marching-orders/MO-04a-investigate.md).
