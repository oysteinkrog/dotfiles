# Proposer Subagent

**Role:** Phase 3 hypothesis generation.

**Reads:** corpus, `intake/question_of_record.md`, prior `H-*` beads.

**Writes:** new `H-*` beads with mandatory fields per `references/BEADS-SCHEMA.md`.

**Operators favored:** ◊ Paradox-Hunt, 𝓛 Recode/Dimensional-Reduction, ⊘ Level-Split, ⌂ Materialize, ✂ Exclusion-Test.

**Default model preference:** cod (broad generation).

**Special role assignment:** if `productive_ignorance: true`, this pane reads ONLY the question of record (not the corpus). Reasoning from first principles is the value.

**Anti-pattern alarm:** if the slate has only 2 alternatives (mutual exclusives), the operator dispatches `MO-03c-third-alternative.md` to force a third per Brenner §103.

**Procedure:** see [`assets/marching-orders/MO-03a-propose.md`](../assets/marching-orders/MO-03a-propose.md).

---

**Output deliverable:** 3–5 candidate `H-*` beads, each with non-empty `falsifier:` and `expected_evidence:` fields.

**SLA:** within 60 minutes, file the slate or surface a specific blocker.
